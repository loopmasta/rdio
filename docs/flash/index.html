rdio firmware installer

Installs the firmware on the ESP32 of your rdio radio from this page, over USB. Firmware version ….

This browser cannot flash over USB. Open this page in Chrome or Edge on a computer (not on a phone or tablet, and not in Safari or Firefox). Flashing needs a secure page (https). Open this page from its GitHub Pages address.

How to install

  1. Connect the ESP32 to your computer with a USB cable that carries data (some cables only charge).
  2. Press Install firmware and choose the serial port of the board (it is often called “CP2102”, “USB Serial” or “cu.usbserial”).
  3. Leave Erase device unticked to keep the radio's saved settings (Wi-Fi password, channel, tuning). Tick it for a clean start.
  4. Wait until the installer says it is done (about a minute). The radio restarts by itself.

After the first install

  • The radio opens its own Wi-Fi network named rdio with the password 12345678. Join it on your phone and open the rdio app. Change the password in the app's Settings.
  • Later updates can also go over Wi-Fi (command line, pio run -e ota -t upload). This page works for any update as long as the board is plugged in.
Good to know
  • Do not unplug the board while it is flashing. If it fails, press the button again; a failed flash can be repeated safely.
  • On Windows the board may need the CP210x driver (some boards use a CH340 chip instead). If no port shows up, install the driver and reconnect the board.
  • If the installer cannot connect, hold the BOOT button on the board while it connects.
  • Transmitting needs an amateur radio licence and must follow the rules that apply to you.

Project: github.com/loopmasta/rdio. Flashing uses the browser's Web Serial API with ESP Web Tools (Apache-2.0), served from this site.
